**预算暴露(E1 解耦的直接后果)**:一个完整"来源→行动"循环 = C4+E1 = 5 槽
⇒ f=0.1 下冷启动最小 B 从 80 降到 **50**;继承同候选合格未消费 token 的续空间,
B=40(Q=4)即可支付 E1/E2/E4 任一行动。冷启动 B=40 仍无 E 结构机会(裁决③,暂不加剂量);
B=20/39(Q=2/3)无完整块,全归 TPE。

## 1. 方法定位(不变,承 v3 §1)

条件局部 OAT 实测 + 精确资源点图 + 有限预算分配;非 Gibbs 链、非坐标下降收敛过程、
非 TPE 替代。TPE 独占搜索与选择;本机制只做探针(不占 trial)、enqueue(只加点)、
供给简报。借入部件与不引入清单见调研稿 §1(MH/退火/bandit/局部 GP 均不引入;
模型选测量点即决策,无例外)。

## 2. 身份、适用性与证据等级(不变,承 v3 §2)

typed 完整配置与搭档投影;同身份+搭档投影逐字段相等才"当前适用";
沿轴 k 自身移动保留 k 的证据,改其他轴降为历史条件事实(可进简报,标注,不作当前上限);
无 `stale_within_noise`。证据等级 screen-fit ≠ real-valid;硬拒绝须必经 kernel
`required>limit` 或可核验 launch OOR;coverage 三态+逐字段 `field_present`;
非单调点图,不二分不外推不称"第一个不可行"。categorical/bool 可有墙、无斜率;
bool 物化不支持记 unsupported。**跨候选迁移、预测性部分搭档匹配:禁止(裁决⑥)。**

## 3. 探针层:U/W 同批交替(v4 修订三处)

**常数**:`Pcap=48` unique 新点/批;每空间 `started_attempts≤4`;至多 1 个在途批,
结算完成前不准入下一批。

**发批条件【v4 修复,替换 v3 的"变化才发批"】**:正常 cadence 到达,且
(a)存在 ready work——U 尾部、缺失向内对照、未回答点、未访四角、回退下一层都算;
(b)无在途批;(c)次数/D/run 预算允许。搭档投影变化与新拒绝只**更新队列**;
初始 bootstrap 显式就绪,不依赖"从无到有算不算变化"。没有 pending 工作不发批。
频繁 churn 时按轴搭档投影合并为最新 origin,每 cadence 至多一批,不每次翻转全量重扫。
在途批冻结完成,不取消重启;旧队列仅取当前兼容项。

**D 预算(承 v3,+小 bootstrap 重试【v4 裁决④】)**:入口有同候选兼容完整批成本
m_ref ⇒ 冻结 `D=min(2·m_ref, 600s)`;无参考准许一次 bootstrap 批(受现行
`prescreen_timeout_s(cfg,n)`、600s、run 余量约束),实耗照计,完整成本到手后冻结 D。
首批超时=截尾 unknown;**可选一次更小规模的 bootstrap 重试**,置于预声明的 600s
剩余额度、实际 timeout 与 4 次尝试上限内——首试全计费、不刷新 D、不退次数,
重试不保证返回。此后该空间停止主动探针(只读的自然生产回答仍可补入账本)。
不承诺全 run <10% 墙钟;实际占用全链计账披露。

**U 回合(不变)**:当前冻结搭档下未知轴点;轴序=最少已提交→最长等待→稳定 ID;
轴内近邻向外,等距先 lower 后 upper;"已覆盖"须精确匹配搭档;categorical 按稳定
typed 值序补覆盖。

**W 回合【v4:有界类别轮转,替换 v3 的固定优先级】**:四个类别——向内对照、
转变邻点、四角模板(每批仍 ≤1 个,原子预留 ≤4 点)、远拒绝回退(≤2 依赖层,
下层等下批)。**非空类别各取一个请求再重复**;类别/模板游标**按尝试推进**
(失败与重试计次,完成另记),坏轴对不得无限占首位。
**四角选对【v4】:TARGETED 与 UNFILTERED 回合交替**(同候选持久游标)——
TARGETED 从真实拒绝与 origin 的差异轴构造局部候选队列(差 5/6 轴 ⇒ 10/15 对),
UNFILTERED 按稳定声明索引在全部 66 对上轮转;无真实拒绝差异或目标队列无合法缺角时
回退未过滤轮转。覆盖尺度如实报:4 批 ≤4 模板 = 66 对的 ≤6%,D 容两批时 ≤3%
——四角是抽查不是普查,"没查到交互"不得写成"没有交互"。

**软墙与隔离(不变,承 v3 §3)**:逐 kernel 保留 value/unit/field_present/read_source/
见证 kernel;winner spill gate 保留;只要求局部上升段;延迟价值不进扫描准入。
独立诊断缓存,永不写生产 `_screen_cache`、不发生产拒绝、不碰 guard/PRUNED。

## 4. 试验层:C4 来源 / E 行动(v4 核心修订)

**配额**:`Q=floor(0.1·B)`(裁决③:f 不动)。C4 启动前原子预留 4 个原 B 槽+4 个
扫描机会;E1/E2 按其行动长度(1/2 槽)预留【v4】;不足不启动;失败/取消耗机会;
未实际 asked 的 B 槽释放给 TPE 但不成为重试信用。原收敛/空间结束/run 时限优先。

**相位(承 v3,+完成钩子与 token 优先)**:新候选从 C 起,准入即翻转;
当前相位无合格项回退另一队列(记录 requested/served);同候选扩展空间延续相位。

### 4.1 C4 块(来源,四槽,协议不变)

合格项、排序、四槽 P2(发现对+验证对、两对内部独立随机、**禁止强制反序**)、
F/N 几何冻结(θ\* 在边界时 N=A、F=向内对照)、旧赢家退出基线、categorical 同预算
无序表——全部承 v3 §4 不变。

**【v4 新增】来源 token**:C4 fresh-complete 且通过来源质量门+正向打印门后,
按唯一 source contrast ID 生成**一次性 pending E token**。未过门的 C 不生成 token。
token 语义:
- **admission 即消费**(含随后失败/取消),不退款、不递归(E 的输出不自动生成新 token);
- 每来源至多一次;当下无预算但来源仍有效 ⇒ 保持未消费,供同候选此后合法空间评估
  (接收空间用自己的 Q/B 付费,不携带旧槽);
- 提交时重新检查:来源未被更新证据否定、精确身份/搭档当前适用、存在合法未测新值、
  剩余预算——任何一项不成立则本次不消费(token 保留,除非来源被否定);
- **来源新旧纪律**:更新的同可比对象**完整 C4** 若为负/unknown/矛盾,必须压下旧
  正向来源(不能只搜历史正值);provisional 形状/E2 降级对比**不得**覆盖旧合格 C4 来源。

**【v4 新增】C 完成钩子**:C4 第四个 trial fresh-complete 后**立即**评估
(来源门→token→新点→预算),不等下一个 10-told 检查点;钩子只调度既有扫描预算,
不在 cadence 外发探针批、不加赠槽、不凌驾空间结束。带 token 的来源在下次决策时
获得**一次**优先消费权(先 E1 再回原相位),防止"fallback C 恰好产出可用来源
却因相位翻回 C 而过期"的命名缺口。

### 4.2 E 行动(v4 解耦:E1 默认 / E2 预登记 / E4 研究)

**合格条件(共通)**:存在有效未消费 token(先前完成、当前适用、双端 fresh 重复、
过打印门的增益段)且同一 screen-fit 分量内存在该搭档下未测延迟的合法新值。
r 推导备忘:分量内合法不同轴值数 r≤2 ⇒ C4 后无 E 新点(几何硬约束,预算修不了,
可用性报告单列);r≥3 仅必要非充分(TPE 可能已测)。

**方向【v4 裁决④:允许向内】**:按观察有利方向延伸——默认朝墙(正向来源),
若来源在朝墙方向为负而向内方向的反向读数过正门,可向内取新点。
反向区间按 `I_rev=[−U/(1−U), −L/(1−L)]` 重算(ρ 不变),**反向须重新过正门**,
百分比不得简单取负。保留原几何方向与墙附着来源的标注。

**协议菜单(裁决②)**:
- **E1(默认,1 槽)**:沿合格方向取一个新值,enqueue(fresh intent)、完整生产
  trial、正常 tell。**不产生新认证斜率、新双端 ρ 或新 P2**;旧 C4 来源照常带全套
  披露打印。E1 是"斜率改变采样目标"的最小单位,其发生本身即 C2 采样侧的施用事件。
- **E2(预登记,2 槽)**:新值+新锚点各单测一次 ⇒ 降级新对比(单端无重复,
  按实际证据等级描述,无自身 P2/双端 ρ);需要新对比时选用,协议事先登记。
- **E4(4 槽)**:两个新值→形状 A0XYA1;一个→P2 新边;仅新曲线研究时选用。
- 协议按问题与事前几何**预选**,不看结果后改名;选点几何承 v3(近墙端外侧紧邻
  screen-fit 未测值→区间内→内侧,不跨未知/拒绝/缺口;不为消费斜率重测旧两端)。

**排序(承 v3)**:声明 choice 步跨度分层→层内最新兼容已完成对比实测增益降序→
最少 E 准入→最长等待→稳定 ID。负向过门事实照进简报,不占改善优先队列
(现行政策;其"纯损失"论证已删除——见方向条款,向内消费是合法替代)。

**必报计数(承分析报告 §1.2)**:accepted/admitted、fresh-completed、
distinct new values、**actual rank-changed selections**(相同合格集合与 RR 次序下
斜率排序真正改变目标的次数——E1 标签数不是科学成功指标);
E 机会漏斗按八门三态 bitset(pass/fail/unknown)+固定首失败序(X,C,F,P,G,A,N,S)
记录,禁止独立相乘与重叠相加。
