## 0. 一页机制图

```
每个检查点(每 10 个完成 trial;incumbent 搭档投影变化或新拒绝时才发新批):
┌─ 探针批(compile-only;U/W 同批交替;Pcap=48 点;每空间 ≤4 次已启动尝试)──┐
│  U 回合:当前冻结搭档下未探过的轴点(最少提交轴优先,轴内近邻向外)          │
│  W 回合:缺失的向内对照 → 已观察资源转变的邻点 → ≤1 个二轴四角模板         │
│          → 远处拒绝的逐维回退(≤2 依赖层,占 W 槽)                        │
│  产出:条件硬墙(必经 kernel 超限,非单调点图)+ 条件 spill 曲线(软墙)      │
└──────────────────────────────────────────────────────────────┘
              │ 只有当前适用的墙轴进入扫描;无墙则零扫描(自然正对照)
              ▼
┌─ 坐标扫描(真实 trial;四槽一块;占 Q=floor(0.1B);候选内 C/E 相位交替)──┐
│  C 块(覆盖):缺新鲜条件对比的墙轴,四槽 P2(发现对+验证对,F/N 几何冻结) │
│  E 块(延伸):仅当存在先前完成、当前适用、双端新鲜重复、过门的正向增益段    │
│              → 沿该方向取未测新值;两个新值→形状 A0XYA1,一个→P2 新边      │
│  锚点全部新测(旧赢家退出基线);所有 trial 走完整生产管线并正常 tell        │
└──────────────────────────────────────────────────────────────┘
              │
              ▼
┌─ 消费(C2 原管道,输入换成条件化实测)────────────────────────────────┐
│  简报:墙(条件化措辞)+ 过打印门的实测斜率数字(I/ρ/τ 门,附披露)        │
│        负向过门事实照报("向墙恶化"),未分辨报 unknown;审计面保留全量      │
│  采样:扫描即投递(enqueue,fresh intent);E 让实测斜率改变下一个目标        │
│  P2′:发现对预测 g_d vs 验证对留出 y —— 真正的样本外检验                   │
└──────────────────────────────────────────────────────────────┘
```

## 1. 方法定位(措辞按调研稿 R1 修正)

本机制是**条件局部 OAT 实测 + 精确资源点图 + 有限预算分配**的组合,
不是 Gibbs 链(无目标分布、无平稳性主张)、不是坐标下降的收敛过程
(单轴局部证据看不到联合改善——构造例:00 处任何单轴移动都变差而 11 好 20%)、
也不是替代 TPE 的优化器。TPE 继续独占搜索与选择;本机制只做三件事:
**探针(不占 trial)、enqueue 建议(只加点)、向简报供给条件化实测事实**。
借入的部件:Morris 的"逐效应声明起点/步跨/搭档"纪律(不冒充完整 Morris,
d=12 一条轨迹就要 13 点);析因的四角交互见证(只做 2×2 补角,不做 2^d);
BE-CBO 的边界追踪调度动机(不引入可行性分类器——模型选测量点即决策,无例外);
racing 的公平区组与固定总额纪律(不引入淘汰赛)。
MH/退火/bandit/局部 GP 均不引入,理由与逐条"可借部件"见调研稿 §1。

## 2. 身份、适用性与证据等级(承 v2/审核,不变部分从简)

- **typed 完整配置**:每点保存全部 PARAMS 的类型化映射(`bool:true/int:1/float:1.0/str:"1"`
  不混同),`config_key` 为其摘要;搭档投影 = 除该轴外的全部键值。
- **适用性**:同执行身份(candidate/source/workload/toolchain/device/协议)且
  当前搭档投影逐字段相等。**沿轴 k 自身移动保留 k 的证据**;改任何其他轴,
  该轴证据降为"历史条件事实"(可进简报,明确标注,不作当前上限)。
  无 `stale_within_noise`——延迟相近不能续用旧墙。
- **证据等级**(审核 M2):`screen-fit`(已触达 kernel 编译资源未超限)≠
  `real-valid`(完整真实 trial 通过);硬拒绝须**必经 kernel** `required>limit`
  或可核验 launch OOR;coverage ∈ {unknown, partial, validated_workload},
  逐字段 `field_present`(`getattr(...,0)` 假零已知);部分覆盖的"未超限"不外推。
- **非单调点图**:`[fit,refused,fit,unknown]` 记两条局部边;不二分、不外推、
  **不宣称"第一个不可行"**(v2 §0 图示与正文矛盾处,按正文,图示已改)。
- categorical/bool 可有墙、无斜率无方向;bool 物化不支持则记 unsupported。

## 3. 探针层:U/W 同批交替

**常数(全局拟预注册)**:`Pcap=48` unique 新点/批;每空间 `started_attempts≤4`
(超时/失败占次数);每空间至多 1 个在途批,结算完成前不准入下一批。

**D 预算(审核 B2)**:入口已有同候选兼容完整批成本 m_ref ⇒ 冻结 `D=min(2·m_ref, 600s)`;
无参考则准许一次 bootstrap 批(受现行 `prescreen_timeout_s(cfg,n)`、600s、run 余量约束),
实耗照计,完整成本到手后冻结 D;首批超时=截尾 unknown,该空间停止后续诊断。
失败不退额度,重启/换 incumbent 不刷新。**不承诺全 run <10% 墙钟**(数量占比≠耗时占比,
审核 B1 的情景表:m=300s 时 D=600s 已占小空间普通工作的 75%);实际占用全链计账披露。

**选点(批内 U,W,U,W… 回合;各回合读批前证据,不依赖批内结果)**:
- **U**:当前冻结搭档下未知的条件轴点。轴序:最少已提交点数 → 最长等待 → 稳定 axis ID;
  轴内:最近声明邻点逐级向外,两侧等距先 lower 后 upper。"已覆盖"须精确匹配搭档
  (边际上同值跑过不算)。categorical 按稳定 typed 值序补覆盖。
- **W**:缺失的向内对照 → 已观察硬/软转变附近未知点 → ≤1 个二轴四角模板
  (θ\* 角+两个单改角+合改角,只补缺角;轴对按稳定声明索引元组轮转,**不**按
  "最可能有交互"选)→ 远拒绝回退(冻结 r 与 a,每层把 r 的一个坐标退回 a,
  只有实际回答仍拒绝的点进下层;≤2 依赖层,下层等下批;回退边的搭档是该层 r 不是 a;
  部分覆盖不称 screen_1_minimal,未知一律 unresolved)。
- W 空则回退 U,U 空回退 W;都空不发批。缓存命中引用原回答,不烧点槽。

**软墙**:同批 spill 读数,逐 kernel 保留 `{value, unit, field_present, read_source, 见证 kernel}`
(`metadata.num_spills` 与 `compiled.n_spills` 来源不同,不得混拼;见证 kernel 切换须标注)。
winner spill gate 保留(θ\* 明确 spill>0 才适用;0=不适用;缺字段=适用性未知;
如实承认漏掉从不 spill 起步的软段)。只要求**局部上升段**,不要求整轴单调;
**延迟价值不进入扫描准入**(避免"没延迟不扫、不扫没延迟"闭环),价值过滤在真实 trial 之后。

**隔离(不变)**:独立诊断缓存,永不写生产 `_screen_cache`、不发生产拒绝、不碰 guard/PRUNED;
生产 screen 已发生的回答只读引用。

## 4. 试验层:C/E 四槽相位机

**配额**:`Q=floor(0.1·B)`(B=20/39→2/3:无完整块,全归 TPE,不发碎片;
B=40→4:至多一个块;B=80→8:至多两个块)。四槽**原子预留**(启动前预留 4 个原 B 槽
+4 个扫描机会;不足四槽不启动;失败/取消耗机会;未实际 asked 的 B 槽释放给 TPE
但不成为扫描重试信用)。原收敛/空间结束/run 时限优先。

**相位**:新候选从 C 起,**准入即翻转**(含随后失败的块;两队列均空则不准入不翻转);
当前相位无合格项回退另一队列(记录 requested/served phase,准入后仍按原相位翻转);
同候选扩展空间延续相位,不因扩展重置。

**C 块(覆盖)**:合格项 = 当前适用墙轴/搭档组合,缺 fresh-complete 条件对比,
且同一已知 screen-fit 连通分量内能选出两个不同端点。
排序:最少已准入 C 尝试 → 最长合格等待 → 稳定 axis/partner ID(失败不总占队首)。
**协议固定四槽 P2**:发现对 `F_d,N_d` + 验证对 `F_v,N_v`,两对内部各自独立随机
(**禁止强制反序**——线性漂移下强制 ABBA 镜像会制造 −(bΔ)² 的人为负协方差,
把好仪器读成发现/验证不一致);首槽前按几何冻结 F=内侧、N=墙侧
(**θ\* 已在边界时 N=A、F=向内对照**,审核 M3;不按快慢/顺序命名)。
**旧赢家退出基线**(审核 S1):历史 incumbent 值只作偏离诊断,四端全部新测。
同轴多墙段按稳定 wall ID 选;覆盖单位是轴/搭档组合,不因细分 wall ID 重复过门。
categorical 墙进同预算无序 C 表:两类别各 fresh 两次、内部随机;
只出条件延迟表+未测项,无方向词,不进 E 排名。

**E 块(延伸——斜率消费点,用户裁决保留)**:
- **合格条件**:存在先前完成、当前适用(同身份+同搭档投影)、**双端均 fresh 重复**、
  过打印门的**正向**增益段;且同一 screen-fit 分量内存在**新 latency 点**
  (该搭档下未测过延迟的不同轴值;screen-fit 过≠可跳过完整 trial)。
- **选点几何(先于本块结果)**:旧近墙端外侧朝墙紧邻 screen-fit 未测值 →
  旧区间内未测值(距近墙端最近优先)→ 紧邻内侧未测值;不跨未知/拒绝/分量缺口。
  无新点则 E 不合格回退 C;**不为"消费斜率"重测旧两端**。
- **协议按几何预选**:两个合格新值→形状 `A0 X Y A1`(双新锚点,X/Y 执行序预随机,
  作图按声明序;中心 `exp((logA0+logA1)/2)`,双锚敏感性并报);
  一个新值→四槽 P2 新边(当前 anchor 重新实测作对照端)。
- **排序**:先按端点声明 choice 步跨度分层(跨轴单位不可比),层间稳定轮转;
  层内按最新兼容已完成对比的实测正增益 `mean(log F−log N)` 降序 →
  最少 E 准入 → 最长等待 → 稳定 ID。**不从历史多段挑最大**;不用 spill/choice、
  绝对负斜率或任何跨资源标量。
- **负向过门事实**:照进简报("当前条件向墙恶化"),不进 E 优先队列——
  (b) 的采样消费**有意限定为正向**(负陡坡的价值在改写侧,采样侧是纯损失)。
- E 的估计对象标 inherited/adaptive 层,与 C 的 coverage P2 分层报告,不池化。

## 5. 打印门与统计(承审核 S2/S3,补调研稿修正)

- 主量:`d=log N−log F`,`g=1−exp(d)`(正=朝墙改善;百分比反向不能取负)。
  `g_d`(发现对)是 P2 预测,`y`(验证对)是留出结果,验证前冻结;
  `g_all` 事后供简报,**不充当预测**。
- **打印门**:`I=[1−max(N)/min(F), 1−min(N)/max(F)]`;
  `ρ=(max−min)/geomean`(每端);`τ=max(4%, ρ_F, ρ_N)`。
  `lower(I)>τ` 报实测改善;`upper(I)<−τ` 报实测恶化;其余简报写"未分辨",
  审计面永远保留全量原始值。过门输出必附:条件搭档、方向/跨度、每点 fresh n、
  每 trial timing n、执行顺序、ρ/I/τ,及"**经验复测包络,非 95% CI**"。
  单测端 ρ=UNKNOWN 不是 0,临时门 `τ_single=max(4%, ρ_重复端)`,过门只可标
  "本会话暂定实测对比,某端单测噪声未估计";**E 资格要求双端重复,临时标签不够**。
- 覆盖率推导备忘:n 对 contrast 极值区间覆盖 `1−2^(1−n)`(n=2 仅 50%)——
  四槽是两对不是四对,不得称 95% CI;中位数区间不套给 mean log ratio。
- **免费诊断**(零成本):每 trial 既有 20 timing 顺带记录 log 尺度 MAD、
  前后半段差、lag-1 自相关+实际时刻——质量门输入,是提示不是独立性证明。
  质量/中止规则与效果符号无关、跑前固定。
- 20 timing 是 trial 内嵌套样本;不拼 n、不 bootstrap 成独立重复。

## 7. 执行接线(审核 E1/E2,实施阻断项)

- **fresh_measurement intent** 必须贯穿 enqueue→ask→测量缓存:现行
  `tpe.py`(`skip_if_exists=True`、`already_drawn` 拒绝、`_seen`→PRUNED)与
  `orchestrator.py:1231-1269`(measured_cache 复制、换 trial_id 发 TRIAL_DONE)
  会让锚点复测**根本不发生或被缓存副本冒充**(假 A/A 零差)。
  例外仅限扫描意图的重复去重与测量复用;guard/正确性/资源筛查/失败语义全不动。
  实施图必须含 `tuning/tpe.py` 与 `control/orchestrator.py` 的适配。
- 四槽完整性:冻结端点不追 live incumbent;区分 planned/pending/told/fresh-complete;
  run 不足即停,记未完成,不换更便宜端点;点记录带
  `scan_id, role, source_trial_id, fresh, order, time`(不建六事件状态机)。
- 记录最小集(审核 §5 拒绝删除项):原始 timing+fresh 身份+顺序;
  发现截止时刻+留出角色;实际批/扫描全链成本(含超时);新旧消费者互斥。

## 8. 模式与对照实验

模式:`off / observe(只探针不扫描) / active`。新旧消费者互斥
(active 臂 legacy 全关,否则双重干预)。

**三层对照(预注册,分层回答不同问题)**:
1. **RR vs C/E**(轴优先政策,首选 head-to-head):两臂相同 U/W/Pcap/Q/D/门/协议选择规则,
   唯一差别是轴优先是否消费实测斜率;RR 臂在相同合格项并集上稳定轮转。
   回答"斜率改变搜索目标是否有用"——S7/step-4 没问出的问题。
2. **off vs active**(C2 整包):回答机制整体的端到端效果;单对 pilot 只报案例效应。
3. **P2′ 留出**:`g_d→y` 的关联/符号/校准(RUN_FINISHED 后读,预测事先冻结;
   全部 planned/admitted/fresh-complete/质量失败/缺失分母保留;缺失=inconclusive 不删);
   同目标同截止可配对读取旧边际预测作对照,不加 trial。
必报可用性观测:有 E 机会的检查点/候选数与无机会原因(伙伴漂移/无正增益/端点耗尽/预算),
未触轴数、首回答等待、C/E 相对 RR 的目标选择差异及证据链。
E 机会在现行预算下稀少(B=40 零 E、B=80 至多一次)是已公布的剂量限制——
深化改进另行进行(用户裁决 ②),答复到达后修订本节。

## 9. 已实测的地面事实(设计依据,引用见调研稿/审核/wrapup)

K=1→3 可达率 2%→4%;ρ(斜率,覆盖)=−0.431 且 14/24 欠覆盖参数有墙

## 10. 红线自检(每条对齐)

不缩空间/不 enforce/B 不变/只加点 ✓(探针只读、扫描占 Q、未用回 TPE);
无任务/knob 特判 ✓(全部阈值为全局拟预注册常数;选点/排序读实际声明 choices);
