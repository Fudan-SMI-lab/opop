# 实施方案 v2 审查：先修测量仪器，保留条件斜率主张

我先纠正自己上一份 final 草案的方向：过量的隔离、认证和记录设计挤掉了科学问题，
又把“暂不打印斜率”当作默认答案，而不是修好能测斜率的仪器。用户拒绝它是对的。
本审查撤回这种默认处理，不为旧稿辩护；需要保留的只是删掉就会导致具体错误结论的设施。
原 C2 假说不变：调参得到的斜率，附着在资源墙上，引导结构改写与采样。
条件探针加坐标扫描值得实施，但有限数据只能支持限定条件、限定会话的结论，不能保证 C2 为正。

## 0. 范围、锚点与总裁决

审查对象是 [implementation-conditional-coordinate-scan.md](implementation-conditional-coordinate-scan.md)，
其标题为“实施方案 v2”，文件位于 `v3/docs/`；下文“v2 Lx”均指该文件行号，不指另一个目录。
本报告完整读取其 235 行，仅新增本文，不改原稿、历史文档、代码、配置或计划。
源码锚点相对 `v3/src/kernel_optimizer/`：
`tuning/tpe.py:L70 至 L72、L96 至 L104、L128 至 L156、L178 至 L220`，
`control/orchestrator.py:L1231 至 L1269、L1270 至 L1280`。这些区段本次已直接读取。
历史预算情景采用任务提供的已核实结果；spill、timeout 与缓存语义另据本次只读源码审查，非实际运行观测。

**总裁决：接受核心；成为可执行、可信的测量仪器之前需修改。**

| 用户优先轴 | 裁决 | 最小修正及错误结论风险 |
|---|---|---|
| ① 机制是否回答原问题 | 接受核心，需修改边界语义 | 保留固定搭档、有限点图；补向内对照，否则把边界最优误写成无斜率 |
| ② 低成本统计与 P2 | 需修改 | 四槽预选形状或留出协议；否则赢家偏差、漂移、同数据自证冒充预测 |
| ③ 数量与墙钟预算 | 拒绝现有墙钟保证 | 保留数量配额，冻结空间 D，公布实际成本；不能声称必低于 10% |
| ④ 生产拦截、任务硬编码与速度 | 需修改 | 扫描限定 fresh intent 穿透普通去重及复用，不穿透正确性或资源 guard |
| ⑤ 删掉的设施是否承重 | 接受大部分删除 | 只保留能区分假复测、泄漏、失败缺失和双重干预的最小信息 |

最低修改不是另建平台，而是确定点几何、四槽角色、打印门、fresh 执行和成本口径。
下面每项都给出接受、拒绝或需修改，并说明尽量不增加原预算的修法。

## 1. 第一优先：条件探针与坐标扫描的机制

### M1. 固定搭档和墙身份：接受，限定归因范围

v2 L49 至 L58、L100 至 L104 的主要修复正确：固定有类型的全部伙伴参数，消除边际桶的成分混合。
墙身份带伙伴投影，另一个伙伴组合在同一轴值成功，不能删除原组合的拒绝事实。
这不是全局因果效应，也不是全部交互效应的地图；只有联合移动才显现的墙可能完全不出现。
v2 L55 的“只含每 trial 噪声”需收窄：编译版本、内核路径、运行状态与时序干扰仍可能改变结果。
因此应称“固定伙伴条件下的实测有限对比”，而不是已经隔离一切混杂的纯结构效应。

### M2. 硬墙、coverage 与非单调图：接受图，拒绝首失败概括

v2 L21 的“第一处”与 L101 至 L102 的“不宣称第一个不可行”冲突，前者必须删除。
继续保存有限 choices 上的 `[screen-fit, refused, screen-fit, unknown]`，不二分、不补全未知边。
`screen-fit` 只表示已触达内核的编译资源未观察到超限；`real-valid` 必须由完整真实 trial 确认。
只有确认属于必经内核的资源超限，才支撑当前配置的硬拒绝；未确认必经性时限定为观察事实。
部分 coverage 的未超限不推出全局可行，也不能写“探针确认可行”后跳过生产校验。
这保留了资源墙证据，并避免把未执行路径当成已经排除的失败路径。

### M3. 点几何：需修改，向内对照是必需而不是扩展功能

v2 L128 至 L131 的相邻、中点、最后可行点可能重合；incumbent 还可能已经处在边界。
先在声明顺序上确定与当前点相连的局部已知 screen-fit 分量，不越过拒绝或未知点拼曲线。
在该分量内去重选择不同轴值；所有点冻结同一完整 typed 配置的其余坐标，并以真实 trial 验证。
若 incumbent 已在墙前，必须向内取至少一个可行对照，按“内侧到边界”定义方向。
锚点 A 仍是边界处的实际 incumbent，不应伪造一个更内侧的 incumbent 来迁就公式。
若分量只有一个可用值，墙仍成立，但没有可辨识的斜率，不能填 0 或认定资源不重要。
软墙没有硬拒绝意义下的“最后可行值”；应选已测 spill 局部上升段的两端或内部值。
不因此把所有退化案例都改成 probe-only；有向内对照就继续保留真实斜率仪器。

### M4. 类别轴：接受延迟表，需补同预算选择器

v2 L114 至 L118 承诺 categorical 条件延迟表，L126 却只选择有序轴，L177 又将全类别当静默原因。
修为类别墙可进入同一 Q 配额的无序选择器：先按固定墙轮转，再按稳定 typed 值顺序取不同值。
表格包括新测 incumbent 及选中的类别值，明确未测项，不按最快结果事后挑展示对象。
类别值之间不打印方向、数值斜率或单调性，数字编码也不改变这一点。
当前 bool 不受支持就明确记录 unsupported，不借本审查扩展参数类型实现。

### M5. spill 软墙与墙选择：需修改，不能复制整个旧判据

v2 L96、L105 至 L107、L137 将 spill 写成无噪声统一量，这个表述过强。
`metadata.num_spills` 与 `compiled.n_spills` 是不同来源路径，必须记录实际来源、字段存在性及内核范围。
字段来源见 `gpu/worker_main.py:L519 至 L531、L777 至 L790`；聚合见 `evaluation/profilerx.py:L57 至 L66`。
逐内核最大值还会切换见证内核；曲线必须注明同范围聚合及见证者，不能暗示一直是同一个内核。
未知字段不补零，编译元数据也不等于运行延迟，更不自动具备跨编译环境的确定性。
扫描准入只用资源观测及已声明的适用条件；延迟价值过滤只能在真实 trial 之后执行。
若把旧判据中的 latency 条件一起搬入准入，会重造“没有延迟就不扫，不扫就没有延迟”的闭环。
incumbent spill 适用门若保留，应明确会漏掉从无 spill 起步的局部上升段，不算普遍软墙搜索。
真实 spill 可以非单调；局部上升定义软段，单调性是测得的形状，不是编译器规律。
不同轴的 spill/choice 单位不可比较，硬墙也可能始终零 spill，不能据原始 spill 斜率全局排名。
最小替代是固定、稳定的墙轮转，保留资源类别和局部段，不引入大型调度框架。

## 2. 第二优先：低成本统计、可打印斜率与真正的 P2

### S1. 旧赢家不是本次基线：拒绝 v2 的噪声底解释

v2 L131 至 L133、L142 的历史值加一次复测，不能产生噪声底或置信度。
构造例：旧赢家 92，新锚点 100，目标 97；旧基线增益 `1−97/92 = −5.4348%`，新基线为 `+3%`。
旧赢家应退出本次曲线，只留下“历史对新测偏离”的诊断；不能并入 n=2，也不能池化成新基线。
一次绝对差可能因两次噪声碰巧相抵而为零；旧点又经过择优，差值会受赢家选择偏差影响。
固定 4% 可保留为暂定实际效应下限，不得称统计分位数、置信门或已标定噪声阈值。
另一个构造例：真实延迟恒为 100，顺序测得 100、97、94、91，旧锚点也是 100。
近端优先会得到假单调和假 9% 增益，A/A 却为零；固定伙伴并未消除时间顺序混杂。
每 trial 的 20 个 timing 是 trial 内样本，不是 20 次独立 trial，更不是 20 个独立 run。
中位数 bootstrap 至多估计给定 trial 状态的条件误差，还需处理自相关假设，不能代替跨 trial 稳定性。

### S2. 两种明确的四槽协议：接受，按目的预选而非按结果改选

共同约束：四个原 B 槽位预留，完整配置固定，实际顺序和时间记录；历史 incumbent 不占据新测身份。
以下 A=incumbent、B=alternative 仅为执行标签；预算章节的 B 表示 trial 总预算，不是端点。
发现前按墙的局部几何冻结 F=内侧/远墙端、N=墙侧端，所有阶段都报告 F→N 的条件增益。
若 incumbent 已在边界，则 N=A、F=B；其余按几何位置定向，不按观测快慢、数值编码或执行顺序定向。
在扫描开始前登记采用哪种协议，不能看到形状好看就报告形状、看到预测正确就改报 P2。

**方案一，形状扫描 `A0 → X → Y → A1`。**

四槽为两次新鲜锚点和两个不同于 A、也彼此不同的轴值，牺牲第三个新值，不增加 B。
内部 X/Y 的物理执行顺序事先随机化；作图时才按声明坐标排序，不能混淆时间顺序与轴顺序。
描述性新锚点中心为 `h=(log A0+log A1)/2`，即延迟中心 `exp(h)`，旧赢家完全排除。
若 A 在边界，则 X/Y 取内侧，曲线仍从内侧排到边界；A 的基线角色不决定图的方向。
以两个新锚点分别重算对比，给出对锚点选择的敏感性；不能默认两端之间真实漂移是直线。
可附对数线性时间插值敏感性分析，但必须标明假设，不自动替换决策用实测值，守住预测红线。
两内点不足或重合时，不硬凑三点形状；两级有限对比仍有用，但没有三点单调性证据。

**方案二，P2 主扫描：发现对 `A_d,B_d`，验证对 `A_v,B_v`。**

仍是四槽，先完成两个新鲜发现端点，再完成两个新鲜验证端点，两对内部顺序分别独立随机且预先固定。
A 是发起 incumbent，B 由探针与固定选点规则确定；两者映射到预先冻结的 F/N，不事后挑最快点。
发现结束立即冻结 `g_d=1−N_d/F_d`，随后才看验证；留出连续结果为 `y=1−N_v/F_v`。
百分比反向不能简单取负：边界 90、内侧 100，朝墙为 `1−90/100=+10%`，向内为 `1−100/90≈−11.11%`。
验证之后，提示可使用两次新鲜 log 对比的均值生成 `g_all`，但绝不能拿它充当 P2 预测量。
具体为 `g_all=1−exp(((log N_d−log F_d)+(log N_v−log F_v))/2)`。
不额外要求 full-eval 配对；已有最终 fresh 配对只有精确测过同一 F/N 两端才是可选外部检查。
仅复测最终最佳配置，不能验证扫描中固定目标的增益，不能作为免费留出对照。
互不重用 trial 消除了代数泄漏，不保证独立：同一扫描仍可能共享漂移、负载和编译状态。
两对独立随机顺序避免强制相反顺序制造漂移诱导的负相关；ABBA/BAAB 可作敏感性或复现实验。
ABBA 不保证随机漂移恰好抵消，尤其执行时距不等时；不能以排列名称替代误差分析。

### S3. 打印与行动门：需修改为可执行规则，不默认封禁数值

审查和审计面始终显示真实逐值数据，包括负值、失败、未分辨边与未测项，不能只留通过门的漂亮曲线。
对预先定向的 F/N 均有新鲜重复的有限对比，以端点 trial 中位数集合定义：
`I=[1−max(N)/min(F), 1−min(N)/max(F)]`；增益点估计取新鲜 log(N/F) 对比均值再转回比例。
定义 `rho_F=(max(F)−min(F))/geomean(F)`，N 同理；双端均重复时 `tau=max(0.04,rho_F,rho_N)`。
I 是经验复测包络，不是 95% CI，也不是总体保证；rho 是观察到的重复差异，不是噪声真值。
所有点均通过生产有效性、原始 timing 质量及预先声明的稳定性检查后，才应用以下实用门：
`lower(I)>tau` 可报“该条件下实测改善”；`upper(I)<−tau` 可报“该方向实测恶化”。
其余在 rewriter 简报保留“斜率方向未分辨”，资源墙仍可报告；不是从审计记录删除数值。
通过门时同时打印方向、跨度、每点 fresh trial 数、每 trial timing 数、顺序、复测差异、I 和 tau。
必须附“经验敏感性区间，非置信区间”；大而稳定的实测增益可按此预登记启发式参与选择。
P2 检验发现期预测量的留出表现；使用发现与验证数据共同计算的行动门，其可靠性未被同一验证对独立检验。
更强的行动门验证需要另行预定协议下未复用的未来结果，不作为默认四槽方案的额外测量要求。

形状方案也按几何取 F/N 实测端点集合；单测端点的 rho 未估计，不是零，不能伪称双端点重复门已满足。
可以用既有、同候选且测量条件相容的重复校准支持单测端点的启发式门，但不强制另开昂贵校准实验。
没有这种校准时，用同一个定向 I 作敏感性计算：单测端点仅以单元素集合代入，不据此宣称其 rho=0。
若 A 是远墙端则 F={A0,A1}；若 A 在边界则 N={A0,A1}，另一端集合取选定值的单测中位数。
临时门为 `tau_single=max(0.04,rho_repeated_endpoint)`；重复端点 rho 的分母仍为其几何均值。
只有 `lower(I)>tau_single` 或 `upper(I)<−tau_single` 才给暂定方向；未重复端点噪声仍未估计。
通过后可打印“本会话暂定的实测条件对比”，并标明哪端单测、噪声未估计，无正式 CI 或受控错误率承诺。
若未过临时门，rewriter 方向仍为 unknown；不把所有单测值一概禁言，也不把临时门冒充稳定性认证。
主 P2 的 F/N、发现/验证角色、预测与结果定义预先冻结；干扰只能按预定规则记质量失败、缺失或 unknown。
不得看过数据后替换验证对、重定义预测量，或把不利主结果改为成功；全部计划扫描仍保留在分母中。
剩余 Q 中预留的复测只另作描述或敏感性分析，不能覆盖主 P2；近门限也不允许重复直到过门。
历史锚点必须新测；复测及未完成均记录，不把不完整主扫描算成 P2 完成，不加赠预算。

**两个构造测量例（不是 GPU 结果）：**
稳定例取 `F_d=F_v=100、N_d=N_v=90`，则 `g_d=y=g_all=10%`，`I=[10%,10%]`，`tau=4%`。
若有效性与 timing 质量均通过，可打印“同搭档朝墙实测条件斜率 +10%，两端各两次 fresh trial”。
同时披露经验包络及顺序，不称置信区间；这个例子说明仪器不是恒定输出 unknown。
漂移例取 `A0=100、X=97、Y=94、A1=91`，预定 A 为远墙端、N=Y，则 `F={100,91}、N={94}`。
`I=[1−94/91,1−94/100]≈[−3.30%,6.00%]`，`rho_F=9/sqrt(9100)≈9.43%`，故 `tau_single≈9.43%`。
输出 unknown，N 的噪声仍未估计；不能把时间顺序中 100→91 的假 9% 单调改善打印成轴效应。

### S4. 斜率和形状解释：接受实测对比，拒绝结构性“无价值”结论

v2 L145 的 `tail_gain` 是无量纲有限对比，不是导数；须报 choices 跨度和移动方向。
可附每 choice 步长的 log 比率，但不能用未归一化的跨 knob“陡峭度”比较异质单位。
v2 L146 至 L149 的严格单调过滤会因微小噪声反转再次误杀；改报“观察形状”和未分辨的相邻边。
只有分辨出的反转才记非单调独立状态；内部曲率未分辨不能推导无墙或无效轴。
负增益只说明当前搭档下这次移动不利，不说明结构改写无价值，不触发整个轴停止。
墙事实与性能标签分开保留；后续伙伴变化时不把旧曲线当当前曲线，也不抹掉其历史真实性。

### S5. P2 检验局部条件增益的留出预测性；完整 C2 由机制对照检验

v2 L80 至 L85、L196 至 L202 应把“旧测量可能失真”写成待检验解释，而不是已经证明旧负结果是幻象。
原 C2 假说本身不变；`g_d→y` 检验同一固定 F/N 目标的局部增益可复现性与预测性。
它不单独识别斜率用于选目标或引导结构改写的因果价值，不能把同目标复测成功直接当完整 C2 成立。
P2 在 `RUN_FINISHED` 后评估，预测量却必须在验证前冻结；结束后再切数据无法补救泄漏。
比较 `g_d` 与留出连续 y 的关联、符号和校准，预先声明最小实际效应及不确定性解释。
不能只报最终胜负，更不能依据验证成功、符号一致或使用验证结果计算的门来筛选 P2 样本。
所有计划、尝试、完成及质量失败分开报告；验证缺失是缺失或 inconclusive，不能当零增益或悄悄删除。
若分析发现期门内子集，门只能使用发现期及更早信息，且仍报告全体与子集分母。
同候选、同 run 的扫描聚类处理，不能把 20 timings 或扫描条数冒充独立 run 重复数。
不强制巨大默认 N；精度不足时诚实报告无法判断，单个四 trial 预测失败不自动否证 C2。
若样本量、精度与检验能力足够而仍排除有用预测关系，可挑战这一具体局部前提，不能仅据此否证一般 C2。
同一目标、同一发现截止时刻读取旧边际预测量，作配对比较即可，不增加运行；不可用后来历史补算。
`off` 对 `active` 测试包含扫描、提示和采样的整个 C2 机制，不单独识别斜率的因果贡献。
这不弱化原假说；局部探针存在性测试与完整机制效果检验回答不同层次的问题，不能互相顶替。
P1 至 P3 成立而 P4 不赚，也可能是预测外推、扫描机会成本或资源解释失败，不全是改写转化问题。

## 3. 第三优先：真实预算与可负担的测量

### B1. v2 墙钟保证：拒绝，数量占比不能替代耗时占比

v2 L173 至 L180 的 76 至 490 秒是提供的历史批成本范围；下表为据此构造的等成本批预算情景。
m 视作冻结参考批成本，D=`min(2m,600)`；“整批数”假设每批都耗时 m，不代表实际必然完成。

| m 秒 | D 秒 | D 内整批数 | D/800 | D/2240 | 四批原始成本秒 |
|---|---|---|---|---|---|
| 76 | 152 | 2 | 19.00% | 6.79% | 304 |
| 150 | 300 | 2 | 37.50% | 13.39% | 600 |
| 300 | 600 | 2 | 75.00% | 26.79% | 1200 |
| 490 | 600 | 1 | 75.00% | 26.79% | 1960 |

前两占比以普通工作基数为分母；若按增加后的总耗时，`600/(800+600)=42.86%`，
`600/(2240+600)=21.13%`，仍不是低于 10%；也不能把空间 D 的和写成全 run 比率。
构造例：4 个扫描 trial 各 100 秒，36 个普通 trial 各 20 秒，扫描占 trial 时间 `400/1120=35.71%`。
它虽只占 10% trial 数；20 个空间各花 600 秒诊断就是 12000 秒，即 200 分钟。
“无墙则零消耗”只能指零扫描，探针已经付费。11 秒加每点 7ms 可列为轻量情景，不保证平均 2% 至 4%。

### B2. 最小默认修正：接受空间配额，冻结参考，不剥夺仪器

保留每空间最多 4 次探针尝试和 `D=min(2*m_ref,600)`，尝试包括超时与失败。
空间入口若已有同候选、同条件的自然生产批完整墙钟，就用它冻结 m_ref，不能借别的候选中位数。
没有参考时明确 bootstrap：先允许一个受 prescreen timeout 及 600 秒上限约束的批尝试。
该次耗时照收一次；若取得完整成本，再冻结 `D=min(2*首次完整成本,600)`。
若已花费达到或超过 D，就不再发批；不得退还首批、重置中位数刷新预算，或把超支伪装成免费借款。
首批超时是截尾成本，不能当成功中位数；最简单是本空间停止后续诊断，不能无成本重试。
600 秒只是诊断执行准入与目标限制，锁外等待、清理等真实成本仍计入账，不能据此声称硬 run 上界。
成功批时长存在完成截尾选择，必须同时披露失败与超时成本，不能只拿快的成功批估计下一批。
空间配额保障公平，不保障全 run 墙钟比例；保留它而删除未经证明的低于 10% 保证，是首选默认方案。

扫描配额修为 `Q=floor(0.1*B)`，拒绝 `max(4,0.1B)` 的小预算膨胀：B=20 得 2，B=39 得 3。
B=40 的 Q=4 优先做一次 P2 四槽，两级有限对比，不承诺三点单调性证据。
B=80 的 Q=8 可按预登记墙轮转再做一次形状扫描，为选中轴增加形状信息。
不能宣传 B=40 免费兼有留出验证与三至四新值形状，也不能保证每空间测两道墙。
主协议至少剩四槽才启动；不足时可做明确标注的描述性两点测量，但不能声称完成 P2 或补造确定性。

### B3. 若低于 10% 是硬资源诉求：需另作取舍，不能藏成本

可选累计准入为 `P_diag+T_scan <= E_ordinary/9`，三项取已发生、互不重叠的耗时。
这样才对应全机制占总耗时不超过 10%；诊断不能给自己生成普通工作信用，重叠等待不能重复相加。
仍须保留空间公平配额，不能退回全局先到先得；剩余信用覆盖拟发批或 trial 估计成本，事后扣实际成本。
估计偏低与无界锁等待仍会超支，因此这个准入也只是软控制，不是严格时间保证。
构造例：E=800 只给 88.9 秒信用，放不下 490 秒批，也放不下 76 秒探针加四个 20 秒扫描。
E=2240 的信用为 248.9 秒，同样放不下 490 秒批；高成本时不能同时保证完整测量和低于 10%。
必须诚实选择较高开销或跳过，并承认后者降低仪器覆盖率；不把严格信用制当默认来饿死机制。
已有 timeout 公式 `min(30+3n,1200)` 在 n=40 时为 150 秒，历史 490 秒批在该配置下不能完整返回。
锁等待在 communicate timeout 外，清理也耗时；历史成本情景不能写成当前 deadline 下的完成承诺。
源码依据：`evaluation/correctness.py:L31 至 L66` 为配置化 timeout，L170 至 L267 为批调用及未回答不缓存语义；
`gpu/worker_client.py:L283 至 L308` 显示先取锁、后 communicate timeout 及超时清理，均为本次只读审查所得。

## 4. 第四优先：生产拦截、任务硬编码与速度

### E1. 新锚点目前不可执行：需修改，这是科学阻断而非工程洁癖

`tpe.py:L70 至 L72` 初始化入队使用 `skip_if_exists=True`；L151 至 L156 又拒绝 `already_drawn`。
即使仅放开 enqueue，L96 至 L100 的 `_seen` 仍会把重复 draw 告诉 TPE 为 PRUNED。
再绕过这一层，`orchestrator.py:L1231 至 L1269` 仍可复制 measured_cache，换 trial_id 发 `TRIAL_DONE`。
因此 v2 L134 所谓普通投递零损耗，不能证明新锚点实际计时；缓存副本会制造假 A/A 零差和假稳定。
最小实施授权是扫描限定的 `fresh_measurement` intent，贯穿 enqueue、ask 和测量缓存读取。
仅对普通重复拒绝与测量复用作显式例外；不能字面要求“任何 PRUNED 都不改”又要求真实重复。
guard、正确性、完整物化、生产资源校验与失败处理全部保留，诊断缓存仍不写生产 `_screen_cache`。
所有实际扫描结果照常 tell TPE，包括重复锚点的 objective；这是声明过的测量干预，不是假装模型未受影响。
源码 L178 至 L220 的正常 tell 语义继续使用；不全局关闭 guard、不额外赠送 B。
v2 L221 至 L230 的实施图必须补 `tuning/tpe.py` 与 `control/orchestrator.py`，否则承诺停留在建议层。

### E2. 四槽完整性与调度：需修改，不新建六事件矩阵

启动前预留原 B 中四槽，不先消耗一个孤立锚点再发现预算不够；冻结所有端点，不跟随 live incumbent 替换。
区分 planned、pending、told 与 fresh-complete：已入队、已返回缓存记录，都不等于完成新测。
run 时间不足就停止并记未完成，不加 B、不把剩余端点偷偷替成更便宜的点。
现有队列与每 job 锁不保证全扫描相邻或独占；记录实际顺序、开始结束时间，并检测中间其他 job。
受干扰时主 P2 按预定质量规则记失败或缺失，不换验证对、不改预测/结果定义；预留 Q 复测仅另作描述或敏感性。
不利主结果及全部计划分母保留，不许宣称现有队列保证协议时序，也不把补测转换成主检验成功。
点记录附 `scan_id、role、source_trial_id、fresh、order、time` 足够串起测量，不需要六类新事件状态机。

### E3. P1、离线补扫、速度与任务硬编码：接受通用设计，拒绝无依据外推

v2 L197 把自然样本全有墙或全无墙当仪器失败不成立；已知正例、负例 fixture 才有预期标签。
最终 incumbent 离线补扫估计的是被选择终点快照的适用率，不是在线轨迹覆盖率，更不是 C2 判决。
v2 L234 的 `explore` 不在所列枚举中，应为 `observe`；不为这一步另增模式。
“空闲后小于一小时”必须给候选数 N、每批成本与 timeout 表，没有这些不能承诺速度。
离线近零只能限定该快照的资源墙出现率，不能据此宣布整个条件斜率机制已被否证。
这些修正不要求任务硬编码、不增加 GPU 检查；只是取消不受数据支持的提前结论。
本次检查的 v2 未提出按具体任务或特定 knob 名称分支；4%、10% 和四槽是全局协议默认值，不是案例硬编码。
但墙轴 0 至 2 个、固定批价或每 trial 20 timings 不能编码为普遍事实或通用上界。
选点应读取实际有序 choices，样本披露读取实际配置与已返回 timings；成本使用实测，不以案例数字代替仪器输入。

## 5. 第五优先：哪些删除成立，哪些信息删了会得出错结论

| v2 L204 至 L217 涉及的设施 | 裁决 | 最小保留及缺失时的具体错误结论 |
|---|---|---|
| 默认 paired8、独立 A/A run | 接受删除 | 用预选四槽；删掉 fresh 身份则缓存被当重复，错误宣布稳定斜率 |
| 七模式矩阵、三记录族状态机 | 接受删除 | 简单点/墙记录足够；删伙伴及字段范围会把别的配置成功当作原墙消失 |
| 简报条数与字符排版上限 | 接受删除 | 不需替代框架；仍披露作用范围，否则历史条件数字被当当前因果结论 |
| 请求三分法大分母体系 | 接受删除 | 保留计划/尝试/fresh 完成/失败扫描计数及候选/run ID，否则幸存者被当总体命中率 |
| 原始 timing、真实重复 ID、顺序 | 拒绝删除 | 没有它们就无法区分漂移、trial 内噪声与独立复测，错误宣称置信度 |
| 发现截止时刻与留出角色 | 拒绝删除 | 没有它们会把 g_all 或验证筛选后的相关当作样本外预测 |
| 实际批尝试与扫描成本 | 拒绝删除 | 不记超时、复测成本会把数量配额误报为低于 10% 墙钟 |
| 新旧消费者互斥 | 拒绝删除 | active 同时开旧边际消费者，会把双重干预效应归给条件测量修复 |

`off / observe / active` 足够；明确 A 臂旧消费者全关，B 臂只启用新 active，估计整包效果。
observe 可作为仅比较消费者作用时的可选基线，不强制第三臂，也不假装 probe-only observe 能测斜率。
这些保留项是防止命名明确的科学误判，不是复活独立认证、庞大事件系统或每次行动前昂贵噪声校准。

## 6. 批准阻断项、修正后的日常流程与证据边界

实施批准前的短清单，按优先级排列：
1. [ ] 修正硬墙/软段和真实有效性语义，补边界向内对照、去重退化与同预算类别表。
2. [ ] 预选四槽形状或 P2；旧赢家退出曲线，发现预测先冻结，验证无结果导向筛选。
3. [ ] 写实用打印门、重复包络与单测临时标签；不把负增益、微小反转或 unknown 当结构无价值。
4. [ ] 显式授权扫描 fresh 去重/复用例外并保留全部生产校验，预留四槽且不增加原 B。
5. [ ] Q 取 floor，D 冻结且失败计费；删除低于 10% 和小于一小时的无依据保证。
6. [ ] 留下最小角色、顺序、失败分母、成本与互斥记录；P1 快照不顶替 P2 或完整 C2 检验。

修正后的常规流程很短：冻结 incumbent 伙伴，按空间预算探针找局部墙，按固定轮转选择测量轴。
预留原预算四槽并执行选定协议，真实新测全部进入正常 TPE；墙与逐值数据保留，过登记门才给方向性提示。
run 结束后用此前冻结的预测对留出增益检验 P2，再看整包对照效果；未分辨就报告未分辨。
这台仪器能给 C2 公平的正负检验机会，不承诺它必然有效，也不把原假说降成资源探针存在性。

本次完成的是全文文档审查、指定源码区段读取及所列算式的文本核对；历史成本由任务提供，并非新跑数据。
构造反例和预算表用于检验逻辑，不是 GPU 实验结果；未运行 GPU、SSH、脚本、回放或生产测试。
未来最小验证包括：已知正负墙、非单调图、边界内侧点、假零、真实重复穿透、留出截止与超时计费。
上述是待实施后的测试清单，不是本次已通过的测试；批准修改后的设计也不等于已证明统计功效或 C2 收益。
