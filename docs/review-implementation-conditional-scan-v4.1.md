### 2.1 方向：原始事实不变，行动方向贯穿

V129 至 V135 冻结原始 F/N、发现/验证角色、`g_d`、`y` 和 P2 分母。
不按结果重定向预测与留出，也不按有无 token 筛掉 P2 留出样本。
V136 至 V140 同时计算 `J_out=I` 与 `J_in=I_rev`，只让 `lower(J)>τ` 的方向发 token。
正延迟下，out 要求 `max(N)<min(F)`，in 要求 `max(F)<min(N)`，二者互斥。
因此每 source contrast 至多一个 token，不是两个方向各发一次，也不是盲取绝对值。
V161 至 V170 分别以有利端 N/F 镜像选点，并保留合法分量与几何回退的证据边界。
V177 至 V182 对 outward/inward 分别使用相反顺序的 log 增益；旧的“墙向负就排除”已废止。
V141、V236 至 V238 仍带符号披露原墙向 g，旁列行动方向和反向区间，不覆盖事实。

V147 至 V153 区分同可比对象键与 immutable contrast ID：前者比较版本，后者唯一消费。
新完整负/unknown 可压旧资格，provisional 或 E2 降级对比不覆盖完整 C4；不同 F/N 不混盖。
V143 至 V145 的通用“来源未被否定”复查也覆盖新 outward 否定旧 inward，无需另补镜像段落。
V211 至 V213 继承的是八门 P/G 等的三态结构和首失败序。
方向判定以 V133 至 V140 的显式替换为准，不能借旧分析的墙向正语义重新排掉 inward。
这是一致解释，不是待补丁项，也不重开既有门政策。

### 2.2 RR：只识别同层增益大小排序

V254 至 V256 让两臂共享资格、方向、相位、优先钩子、预算及协议规则。
结合 V177 至 V182，唯一差异是同跨度层内 gain 排序与稳定 RR 轮转。
V259 至 V263 的池大小至多一证明有明确前提：冷启动、串行 C、即时消费、无继承 pending。
这不是所有轨迹的定理，也不是要求延迟消费积攒来源的理由。
V264 至 V267 记录 pending、eligible、同跨度竞争集及同一 policy snapshot 的两个目标。
RR target 纯计算，不调用 ask，不改变 RNG、队列或游标；分层在新点结果出现前定义。
V268 至 V271 明确零竞争时只能说未识别排序价值，不能判有效、无效或 C2 为假。
E1 施用事件是调用口径，不等于反事实目标发生变化，更不等于完整 C2 已成立。
V47、V301 至 V302 的 C2 文字在 V249、V253 至 V271 的限定下表达政策意图与整包主张。
它们不扩大 RR 的估计对象，未形成交叉矛盾；V272 至 V274、§11 的可选对照不重开。

### 2.3 rho：有合格重复才可观测

V217 至 V224 保留 20-timing 嵌套性；单 trial 内代理不等于跨 fresh trial 重复差 rho。
双端 rho 要求两端各有同完整配置、同执行条件的真实重复，缓存复制或换 ID 不算。
V225 至 V226、V250 至 V251 对缺少兼容 fresh 重复明确记 UNKNOWN，不用 CV 或代理补值。

它不是实际 E 失败率；R136 至 R140 指向的既有 E 分析限定仍承接，不另造数学阻断。
V230 区分零额外 latency trial 与编译、主机成本，未把 observe 说成全链免费。

## 4. 两处作者选定：规则固定且内部一致

### 4.1 相位选定

V198 至 V209 采用普通准入按 requested 翻转、token 优先准入独立处理的确定策略。

| C 准入 requested/served | C 后普通相位 | 随后 token 优先 E 成功 admission 后 |
|---|---|---|
| C / C | E | 显式设 C。 |
| E / C，fallback | C | 显式设 C。 |

该表逐行对应 R182 至 R189；不执行通用 flip 后再 restore，也不争论另一策略是否更好。
优先 admission 失败则相位不变、token 不消费；成功后即消费，随后失败/取消不退，见 V143、V207 至 V208。
执行登记的 action kind，未把优先消费偷换成强制 E1；作者选定已足够确定，不留实施歧义。

### 4.2 冻结前缀缩点选定

V97 至 V99 固定 `n2=ceil(n1/2)`，取原批冻结声明顺序前缀，不按首批结果选点。
整数 n1≥2 时，n2≥1 且 n2<n1；n1=1 由 V88 明确停止。
若该唯一算出的 n2 的 timeout 不适配余量，就不重试，不能再次减半形成隐藏自适应策略。
示例仅沿用既有模型 `T(n)=min(30+3n,1200)`，不是所有配置的 timeout 定义。
n1=48 得 n2=24、T=102；剩余 101s 不准重试，102s 只通过时间额度门，仍需 run/次数门。
本轮纯算术已核对 n1=2 至 48 的全部 47 个严格缩小案例，没有 runtime 调用。
前缀仍可能含失败点，重试仍可失败；截断四角可能留下 partial/unknown，现有覆盖语义可以表达。
这些是已定规则允许的结果，不是新矛盾，不要求结果驱动选点或重复缩小。
