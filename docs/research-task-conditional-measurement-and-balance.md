**四个目标(探索未知空间 / 优先高斜率轴 / 优先找墙 / 优先逼近最优)之间如何分配预算**。

## 3. 调研任务(R1–R3,每条都要"方法→本框架适配性→取舍"三段)

### R1. 条件化测量策略族:Gibbs 坐标扫描的替代与改进

对下列方法族(不限于)做文献+实践双线调研,评估各自作为**测量仪器**(不是搜索策略——
搜索归 TPE)在本框架的适配性:

- **坐标法族**:Gibbs / 坐标下降 / 循环坐标扫描(现行方案);ATLAS/FFTW 等自动调优器的
  正交线搜索实践;何时锯齿、何时停非驻点、离散有序域上的已知修正。
- **接受-拒绝族**:Metropolis–Hastings 式局部移动(提议=单轴一步,接受概率随延迟比)——
  它天然做"温和的方向偏好"而不硬排序;模拟退火。注意:本框架**选择权必须留给 TPE**
  (机制只能 enqueue 建议),MH 的"接受"要如何映射才不越权?
- **筛选设计族**:Morris elementary effects / one-at-a-time 筛选(与坐标扫描形式几乎相同,
  但有成体系的多起点+效应统计;逐轴效应的 μ*, σ 读法);析因/超饱和设计在离散小域上的用法。
- **局部模型族**:信赖域局部 BO(TuRBO 类)、局部 fANOVA/参数重要性(CAVE 类)——
  注意红线:surrogate 预测**不得进门**(判据/排序),但"用局部模型决定下一个测哪"
  是否算违规?给出你的划界论证。
- **约束边界族**:BE-CBO、SCBO、可行性分类器——我们有 7ms 的编译器 oracle,
  这些方法里哪些组件在有精确 oracle 时仍有价值(如边界追踪的调度),哪些是替代品(可弃)?
- **赛马/淘汰族**:racing(irace)、successive halving——用于"多个墙轴竞争扫描预算"时
  的分配,是否比审核裁定的固定轮转更好?代价是什么?

**必须回答**:现行"探针批(找墙)+ 四槽扫描(测斜率)"在这个方法地图上的位置;
哪个替代/混合在**同等预算**(每空间 ≤4 探针批 + Q=floor(0.1B) 个 trial)下信息量更高;
以及每个建议的**失败模式**(它在什么数据形状下会给出错误结论)。

### R2. 四目标平衡(这是现行方案的真空白,重点)

框架里有四个隐性目标:**(a)** 探索未知参数空间;**(b)** 优先检查斜率高的轴;
**(c)** 优先找墙;**(d)** 优先逼近最优点。现状(已核实,见 §4 事实清单):
这四者**从未被显式平衡过**——(a)(d) 由 TPE 隐式承担(startup 随机 + TPE 采集),
(c) 过去是被动的(等拒绝发生),现行方案改为主动探针但剂量固定,
(b) 旧机制唯一的仲裁点是"最陡优先"排序,已被审核降级为固定轮转
(理由:跨轴 spill/choice 单位不可比 + S7/step-4 两次实测斜率大小不预测胜负)。
预算分配是静态的:~90% TPE、≤10% 扫描。

**你的设计任务**:要不要、以及如何把这四者做成显式的分配机制?候选思路(不限):
- bandit 元控制器(每轴/每目标一个臂,回报=实测改善);注意"回报"必须是已实现实测量;
- 采集函数加权(TPE 之外叠加可行性/覆盖项)——注意不得改 TPE 本体与 PRUNED 语义;
- 简单静态配比 + 阶段切换(早期偏探索/找墙、后期偏斜率/最优)——如果你论证静态就够,
  也要给出论证与失败模式;
- 覆盖驱动:已有实测 ρ(斜率,覆盖)=−0.431、24 个欠覆盖参数里 14 个本来就有墙 ⇒
  "采没采过的"就能找到大多数墙——这是否意味着 (b) 应该并入 (a)?
**边界**:TPE 的采样、guard、PRUNED、per-space 预算 B 都不可改;
机制只能通过 enqueue(只加点)和探针(不占 trial)影响分配。

### R3. 小样本斜率统计(校验/改进审核的四槽协议)

审核给出两种四槽协议(形状扫描 A0→X→Y→A1;P2 发现对+验证对)与打印门
(重复包络 I vs τ)。调研:配对设计/顺序效应/漂移控制在 GPU 微基准测量中的
已知做法(如 interleaved timing、随机化区组);次序统计区间 vs bootstrap 在 n≤4 时的
覆盖性;是否存在**同预算下更高效**的设计(如 A0 X A1 Y A2 五槽交错)。
若审核的协议已是同预算最优,明说;若有改进,给出具体替换并证明不增加预算。

## 4. 已实测事实清单(设计必须与之相容,来源都在必读材料里)

- 单 trial 计时 std ≈16%;重调同空间摆 2.1%;复测缺口 ±2–4% 符号不稳。
- 消融从 θ\* 出发 6/6 可归因、默认点 1/6 ⇒ 条件化必须锚在高性能点。
- 探针批:边际 ~7ms/点 + 批固定 ~11s,但多 kernel 候选实测 76–490s/批;
  现行批 timeout 公式 `min(30+3n,1200)`。
- 投递路径三次实测零损耗(建议数=投递数=零拒绝)。
- 斜率大小不预测投递点胜负(S7 与 step-4 两次,合计 3 赢 11 输)。
- 换搭档跑通会抹掉边际判据下的墙(NUM_WARPS=16 实测);墙数随 trial 单调减。
- "采没采过的"与墙高度重合(ρ=−0.431;14/24 欠覆盖参数已有墙)。
- 加宽域 5 次 0 次让最优落在新值上;K=1→3 的 1-knob 可达率 2%→4%。
- 预测数字禁止进决策(v2 实测:中位符号误差 −5%、8/21 符号错)。

## 5. 红线(违反任一即否决,与前两轮相同)

1. 不缩小/限制搜索空间;墙只记录不 enforce;trial 预算 B 与分配不改;投递只加点。
2. 禁止针对单任务/单 knob 的特判与硬编码;一切阈值是全局预注册常数。
3. 进入判据/排序的数字必须是已实现实测量;surrogate/预测收益不得进门
   (R1 里若主张例外,必须给出明确划界论证,由用户裁决)。
4. 噪声纪律:效应量不过噪声门不打印方向/数字(审计面保留全量原始值)。
5. 正对照义务:任何判据必须在受控 fixture 上同时产出正/负例。
6. C2 主张不弱化:"调参斜率附着在资源墙上引导结构改写与采样"原话保留;
   你设计的是**能证实也能证伪它**的仪器,不是替它辩护或替它退场。
7. 成本按墙钟计(数量占比≠耗时占比,见审核 B1),给出最坏/典型两档估计。
