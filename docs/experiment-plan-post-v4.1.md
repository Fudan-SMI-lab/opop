## 压缩的三条杠杆与两条不可压缩的硬约束

**杠杆:**
1. **独立 observe run(12h)取消**:被动五项里四项(预算暴露分布、搭档生存窗口、
   r 分布、兼容 fresh 重复的 ρ 存在率)可直接从既有 step-4/S7 events.jsonl 挖出
   (E 分析 §9 的表已确认),0 GPU;第五项(自然墙/分量几何、探针回答率)
   折进 active pilot 的探针层测。代价:失去"未受干预路径"的几何读数——
   §11 重议没有任何一项依赖它,接受。
2. **pilot 双任务并行**:box4 两张卡同时跑任务 A、任务 B 各一个单臂 pilot,
   一次 12h 拿到两个场地的仪器读数,顺便解决"复制场地怎么选"。
3. **第二台双卡机器 = 两个 12h 对同天并行**:主对照对(box4)与
   RR 对/复制对(box B)并行,省 12–24h;并腾出空间跑原计划塞不下的
   **A/A 噪声底对**。

**硬约束(不可违反):**
- **单 run 的 12h 不能缩**:8/8 历史 run 由墙钟结束、4/4 冠军在后半程到达、
  step-4 首次投递在第 37 次重算(约 4.2h 后)——缩短 run 会砍掉恰好要测的现象。
- **同一对的两臂必须同机**(box1/box4 CPU 不同:compile_s +32%、job_wall +26%、
  核延迟反向)⇒ 第二台机器只能承载**完整的对**,不能跨机拆臂;
  跨机结果分层报告,不并表。

## 排程必须按 12h + 超时量,不是 12h(2026-09-15 实测)

`wall_clock_hours` 是「**不要在此之后开始新一轮**」的地板,不是硬天花板:
墙钟只在**族边界**(`orchestrator.py:2893`)与**候选批边界**(`:3306`)检查,
不在 trial 中间——停在没有半成品的边界上是正确取舍,代价是最多超出一整轮。

**实测超时量**(`scripts/audit_wall_clock_overshoot.py --cap 12 <runs_dir>...`,
step-4 对子):**+1.09h 与 +1.57h,中位 +1.33h**。
窗口 1 复现同一形态:四个 run 在 12.0–12.14h 时最后一次全局判决仍是 continue
(分别在 11.69 / 4.87 / 10.34 / 10.57 h),此后在轮内继续跑 trial。
⚠ P2 那一轮从 4.87h 跑到 12.1h = **单轮 7.3 小时**,所以"最多一轮"的上界可以很大。

**排程写法**:窗口 N+1 的开始时间 = 窗口 N 开始 + 12h + **1.5h 缓冲**;
门 2 的 1–2h 读数正好落在这段缓冲里,不额外占时间。
**不要**用 `wall_clock_hours` 直接算下一窗口的启动时刻——会系统性偏早,
而偏早的后果是两个窗口的 run 抢同一张卡(每张卡上的延迟全部污染)。

## N1 噪声底的适用范围(2026-09-15 补,判读前必读)

N1 与 M1 **共用同一个冻结种子集** `runs-v4/m1-seeds`(四个候选,`source_sha` 已逐位核对)。
这是设计意图——只有同种子同机的 A/A 才是 M1-P3 的正确分母——但它划定了三条边界,
论文措辞必须落在边界内:

1. **N1 给出的是「这四个种子上的」配对噪声底,不是任务级噪声底。**
   换一批种子,底可能不同(记忆:非配对的种子差异可达 5.90%,超过臂内跨度)。
   报告写法:"paired A/A floor on the shared seed set", 不写 "the task's noise floor"。
2. **对等性按总 GPU 墙钟读,不按 trial 数。** 窗口 1 实测:n1-a 680 trial / 3.95h GPU
   vs n1-b 747 trial / 3.55h ——**trial 多的那臂 GPU 时间反而少 10%**(扩展后的空间里
   trial 更便宜)。按 trial 数检查会把健康的 A/A 判成不对等,且方向相反。
3. **两臂是否终结在同一血缘要单独报。** 若两臂的赢家来自不同种子,端到端差里就含
   "哪条血缘走运"这一项,它比测量噪声大得多(step-4 的 −2.31% 全部来自单臂独有的候选)。
   `scripts/probes/v41_n1_noise_floor.py` 分三层印:种子配对核对 / 逐种子调参差 / 端到端差 + 同血缘判定。

## 与论文的对接(不变,承 v1)

- "能测出真斜率" ⇒ M1 P2′(主)+ P1/P2 三率;
- "引导采样" ⇒ M1 P1 剂量分离 + 投递点终局胜负 +(若可识别)M2a;
- "引导结构改写" ⇒ 墙简报交付数 + 改写假设来源分布翻转;
- 端到端延迟差按 N1 标定的噪声底如实报告功效限制,不作主判据;
- 全部负结果同样可发表:预注册+三次历史复现链+条件化修复的完整叙事。
