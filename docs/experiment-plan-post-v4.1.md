## 总原则(从 S7/step-4 两对实验学到的,全部编入设计)

1. **先便宜后昂贵,每级有决策门**:observe(零额外 latency trial)→ 有界 active
   pilot(单臂)→ 12h 对照对。任何一级发现结构性问题(如 E 机会≈0、ρ 全 UNKNOWN、
   r≤2 占比过高)都在烧 12h 对之前修——step-4 的教训是仪器坏了也要等 12h 才知道。
2. **对照对必须种子配对**:step-4 两臂零共享候选 ⇒ −2.31% 落在噪声底内不可读。
   新对照对两臂用相同 seed 候选集(generator 输出固定后分发两臂),
   端到端差异才可能逐候选归因。
3. **对等性按总 GPU 墙钟**,不按 trial 数(S7:trial 数差 12% 但中位 job_wall 相同)。
4. **判读只在 RUN_FINISHED 之后**(中途手算曾反转判决);计数器只读终值
   (累积+单位不同,跨事件求和得三角数)。
5. **预注册**:每个实验的预测、主/次终点、判读规则在启动前写死并提交
   (斜率大小预测被否证的教训:预注册让否证成为可发表证据而不是尴尬)。
6. **仪器自检泛化**:臂名/run 名一律来自参数(臂名写死曾把自己的 worker 报成外来租户);
   GPU 分离在运行期查并存盘(快照无证据力);监控节奏 30 分钟。

## 阶段 0:实施验证(不是实验,但挡在一切实验前)

**在 Windows 上跑逻辑测试,在 box4 上跑 GPU 测试;Windows skip 在 box4 上是 FAIL。**

- v4.1 §9 六个纸面 fixture 全部落为可执行测试(方向 mint 互斥、B=20 继承/冷启动、
  bootstrap 200s 不重冻、轴对 28/66/120、唯一来源 RR=gain)。
- **每个阴性判定配正对照**(阴性结论必须有会大声失败的正对照):
  - fresh_measurement intent:构造"缓存里已有同配置"的场景,断言锚点复测
    产生了**新的** fresh trial(新 job 工件),而不是 measured_cache 复制换 trial_id
    的假 A/A 零差——这是 v3 审核 E1 的实施阻断,必须有专门测试。
  - token 双向互斥:构造 J_out 与 J_in 都不过门、只 out 过、只 in 过三种数据,
    断言 mint 数为 0/1/1 且方向正确。
- box4 冒烟:真实候选跑一个 U/W 探针批(compile-only),核对硬墙/软墙落盘格式、
  D 计账、48 点 Pcap、bootstrap 分支实际走向;一次 C4+E1 全链(active 小规模)
  确认 enqueue→ask→tell 贯通。
- 通过标准:测试矩阵全绿(box4 上无 UNVERIFIED)+ 冒烟事件流人工核读一遍。

## 阶段 1:observe 模式运行(测五项,给 §11 重议供料)

**形态**:box4 单臂 1 次完整 run(observe 模式:探针照跑、扫描不做、行为零干预),
任务用 step-4 同款(与既有两对可比)。预算同既有 run(12h 墙钟)——observe 的
额外成本只有编译探针+主机,不占 latency trial。

**产出(v4.1 §8 的 observe 五项)**:
1. B 分布与首/续空间分层的预算暴露(多少空间 B≥50/=40/≤39;继承 token 机会有多少);
2. 每轴 typed 搭档生存窗口(E 提交时"当前适用"能活多久);
3. 既有点 novelty:r 的分布(r≤2 占比 ⇒ 几何硬约束吃掉多少 E 机会);
4. 自然墙与分量几何(硬墙/软墙出现率、连通分量形状、U/W 回答率、超时截尾率);
5. 兼容 fresh 重复的 ρ 代理(存在多少真重复;不存在则如实报 UNKNOWN 率)。

**决策门 1(observe 后,与用户一起过)**:
- 若 r≤2 占比高 / B 分布使暴露≈0 ⇒ 先重议 §11 的 f 剂量(0.125/0.15),再进阶段 2;
- 若探针 D 占用远超预期(bootstrap 大量超时截尾)⇒ 先修 timeout/批规模再进;
- 否则直接进阶段 2。

## 阶段 2:active pilot(单臂有界,测只有 active 能测的三率)

**形态**:box4 单臂 1 次 active run(全机制开启),同任务,12h。
**这不是对照实验,不回答 C2**;它回答"仪器在生产环境里走不走得通"。

**产出**:
- fresh C 完成率 / 符号率(墙向正 vs 负 vs unknown)/ 打印门通过率(三率);
- E 八门三态 bitset(X,C,F,P,G,A,N,S 固定首失败序)——损耗到底在哪一门;
- 四计数:accepted/admitted、fresh-completed、distinct new values、
  actual rank-changed selections;
- **同层竞争机会**:每次 E 决策的 pending/eligible/同跨度竞争集大小,
  `eligible≥2` 的发生频率——直接决定阶段 3 要不要跑 RR vs C/E;
- P2′ 机器全链演练(g_d/y 冻结、留出读取)——量少也要确认管线正确;
- 全链成本账:探针 D、扫描 Q 实耗、E 行动占用 vs 省槽。

**决策门 2(pilot 后,§11 正式重议)**:输入=observe 五项+pilot 三率+bitset。
- E 准入≈0 且首失败集中在 X(预算暴露)⇒ 批 f 剂量后**重跑一次 pilot**再进阶段 3;
- 首失败集中在 F/G(完成率/过门率)⇒ 回实施层修(可能触发统计协议重议,裁决⑤);
- `eligible≥2` 频率≈0 ⇒ 阶段 3 的 RR vs C/E 降级为"记录性对照"或取消(见下);
- 各率健康 ⇒ 进阶段 3。

## 阶段 3:主对照对 off vs active(C2 整包证据,论文主实验)

**这是三层对照里唯一直接回答 C2 端到端的一层,优先级最高。**

**设计**:
- box4 同机双臂并行(两卡各一臂,CVD 在启动命令里,运行期 GPU 分离检查存盘),
  12h×2,总 GPU 墙钟对等;
- **种子配对**:generator 产出冻结后同一候选集分发两臂(消除 step-4 的种子混杂);
- off 臂 = v4.1 机制全关(legacy 消费者也关——两臂新旧消费者互斥,避免双重干预);
  active 臂 = v4.1 全开;
- 预注册终点:
  - **P1(剂量分离)**:active 臂 E 准入/投递数 > 0 且 off 臂结构性为 0(仪器口径);
  - **P2′(仪器有效性,主科学终点)**:g_d→y 留出关联/符号/校准——
    "条件化斜率是不是真测量"的直接检验,样本=全部 fresh-complete 的 C4;
  - **P3(端到端)**:终局 best 延迟差——**预注册即声明其功效受限**
    (噪声底 ±2.35%,两对历史全部不可分;P3 不分离不否证 C2,P2′ 才是主判据);
  - 次终点:墙简报交付数(两对历史均为 0,>0 即是质变)、改写假设来源分布
    (analyst H1/H2/H3 vs 墙简报——第三次复现的对照)、投递点终局胜负
    (只在 RUN_FINISHED 后判)。
- 判读纪律:逐候选归因(两臂共享候选使之可行);胜负/最优只读 RUN_FINISHED.summary。

## 阶段 4(条件触发):RR vs C/E 对照对

**仅当决策门 2 显示 `eligible≥2` 有非平凡频率才作为独立 12h 对跑**
(v4.1 §8:单来源池下排序价值结构性不可识别——竞争机会≈0 时这对照烧 24h GPU
只能得出"本样本未识别",不值得跑)。
若频率低:不跑独立对,改为从阶段 3 active 臂的决策记录(RR target vs gain target
差异频数)出**记录性结论**,如实报告"排序价值在本预算尺度下不可识别"。

## 阶段 5:收尾分析与可选补充

- P2′ 全量分析(阶段 2+3 的所有 C4 合并,分层不池化);
- §11 二轮重议:token 续期、历史冻结搭档 E、多段覆盖键——用阶段 3 的 bitset 决定;
- 可选(须另批):slope-aware vs blind-geometric(检验单 token 的 USE 效应);
  第二任务复制(21/43/48 中另选一个)——若阶段 3 结果为正,复制优先级高于新机制。

## 与论文的对接(哪个实验支撑哪句话)

- C2 主张("调参斜率附着在资源墙上,引导结构改写与采样")的证据结构:
  - "能测出真斜率" ⇒ 阶段 3 P2′(主)+阶段 2 三率(仪器);
  - "引导采样" ⇒ P1 剂量分离 + 投递点终局胜负 + (若可识别)阶段 4;
  - "引导结构改写" ⇒ 墙简报交付数 + 改写假设来源分布翻转(vs 三次复现的全 analyst);
  - 端到端延迟差如实报告功效限制,不作为主判据。
- 全部负结果同样可发表:预注册+三次历史复现链(S7/step-4/新对)本身就是
  "边际测量层无效,条件化测量层作为修复"的完整叙事。
