**预算暴露【v4.1 修正限定词】**:一个完整"来源→行动"循环 = C4+E1 = 5 槽
⇒ f=0.1 下**冷启动**最小 B 为 50;冷启动 B=40(Q=4)只够 C4 无行动;
冷启动 B=20/39(Q=2/3)无完整块,全归 TPE——**"全归 TPE"仅对冷启动或无可用
继承来源的空间成立**。继承同候选合格未消费 token 的续空间,最低条件是
`Q_remaining ≥ 行动长度 e`(E1/E2/E4 的 e=1/2/4)并通过 B、时间、新点、
身份/搭档各门:B=10(Q=1)可支付 E1;B=20(Q=2)可支付 E2;B=9(Q=0)不行。
续空间与首空间分母分开报,不得混用;B≥50 只是预算暴露,不保证各门通过。

## 1. 方法定位(不变,承 v3 §1)

条件局部 OAT 实测 + 精确资源点图 + 有限预算分配;非 Gibbs 链、非坐标下降收敛过程、
非 TPE 替代。TPE 独占搜索与选择;本机制只做探针(不占 trial)、enqueue(只加点)、
供给简报。借入部件与不引入清单见调研稿 §1(模型选测量点即决策,无例外)。

## 2. 身份、适用性与证据等级(不变,承 v3 §2)

typed 完整配置与搭档投影;同执行身份+搭档投影逐字段相等才"当前适用";
沿轴 k 自身移动保留 k 的证据;无 `stale_within_noise`。证据等级 screen-fit ≠
real-valid;硬拒绝须必经 kernel `required>limit` 或可核验 launch OOR;
coverage 三态+逐字段 `field_present`;非单调点图不二分不外推不称"第一个不可行"。
categorical/bool 可有墙、无斜率。**跨候选迁移、预测性部分搭档匹配:禁止(裁决⑥)。**

## 3. 探针层:U/W 同批交替(v4.1 修订两处)

**常数**:`Pcap=48` unique 新点/批;每空间 `started_attempts≤4`;至多 1 个在途批。

**发批条件(承 v4)**:cadence 到达 + 存在 ready work + 无在途批 + 次数/D/run 允许;
变化/新拒绝只更新队列;没有 pending 工作不发批;在途批冻结完成,不取消重启。

**D 预算与 bootstrap【v4.1:五分支确定表,替换 v4 的混合文字】**:

| 入口情况 | 预算与后续 |
|---|---|
| 已有同候选兼容完整批成本 m_ref | 冻结 `D=min(2·m_ref, 600s)`,正常准入,不因后续结果重置 |
| 无参考,首批完整成功(成本 c1) | 首批实耗照计,冻结 `D=min(2·c1, 600s)`,**余量足够可继续**(不是一律停) |
| 无参考,首批超时 | c1 全计费;预声明 BOOTSTRAP 总额 600s 内**可选一次更小批重试** |
| 首批超时但 n=1,或余量/次数不足 | 无法合法缩小或准入 ⇒ 不重试,停止本空间主动诊断 |
| 首批非超时失败 | 默认停止(不扩张成通用失败重试权) |

重试约束:同时受剩余 600s 额度、现行 `prescreen_timeout_s(cfg,n)`、run 余量与
每空间 4 次已启动尝试上限约束;首试全计费、不退次数;**重试无论成败,之后停止
本空间主动诊断**(成功答案可用,只读的自然生产回答仍可补入账本);
**不得用重试成本重新冻结 D**(首试 170s 超时+重试 30s 成功 ⇒ 已花 200s,
不能重冻 D=60 再解释旧账)。600s 与 timeout 是准入/执行限制,锁等待与清理在其外,
不据此宣称全 run 硬墙钟上界。
**缩点规则【v4.1 作者选定,事前声明】**:重试批 = 原批冻结声明顺序的**前缀**,
规模 `n2 = ceil(n1/2)` 且须使 `prescreen_timeout_s(cfg,n2)` 落入剩余额度;
成员由冻结顺序决定,**不得按首批结果挑选**。

**U 回合(不变)**:当前冻结搭档下未知轴点;轴序=最少已提交→最长等待→稳定 ID;
轴内近邻向外;"已覆盖"须精确匹配搭档;categorical 按稳定 typed 值序补覆盖。

**W 回合【v4.1:轴对数参数化,承 v4 有界类别轮转】**:四类别——向内对照、
转变邻点、四角模板(每批 ≤1 个,**原子预留 ≤4 个 W 点槽,预留不是免费点**)、
远拒绝回退(≤2 依赖层)。非空类别各取一个再重复;游标按尝试推进,完成另记。
**轴对全集 = `choose(d_eligible, 2)`**(66 只是 d=12 的例子;d=8→28,d=16→120);
eligible 轴 = 类型受支持且 ≥2 个合法声明值,**资源状态 unknown 不排除整个轴**。
覆盖尺度如实报:d=12 时 4 批 ≤4 模板 = 4/66 = **6.06%**,D 容两批时 2/66 = **3.03%**
(不写 ≤6%/≤3% 的整数上界)。四角 TARGETED/UNFILTERED 交替(同候选持久游标);
TARGETED 队列无合法缺角时回退未过滤轮转,**回退仍用同一轴对身份去重**,
记录 requested/served,不混淆轮转进度。**组见证前提【v4.1】**:四角"单独各自装得下、
合起来超限"必须以完整 scoped 2×2 的实际回答+逐字段检查为前提——
模板尝试≠模板完成,字段 unknown 仍是 unknown,不自动得出组见证。

**软墙与隔离(不变,承 v3 §3)**:逐 kernel value/unit/field_present/read_source/
见证 kernel;winner spill gate 保留;延迟价值不进扫描准入。独立诊断缓存,
永不写生产 `_screen_cache`、不发生产拒绝、不碰 guard/PRUNED。

## 4. 试验层:C4 来源 / E 行动(v4.1 核心修订:方向链贯通)

**配额**:`Q=floor(0.1·B)`(裁决③:f 不动)。C4 启动前原子预留 4 个原 B 槽+
4 个扫描机会;**E1/E2/E4 按行动长度 1/2/4 各自原子预留(E4 = 4 个 B 槽+
4 个扫描机会,补 v4 漏写)**;不足不启动;失败/取消耗机会;未实际 asked 的
B 槽释放给 TPE 但不成为重试信用。原收敛/空间结束/run 时限优先。

### 4.1 C4 块(来源,四槽)与 token 生成【v4.1 修订入口】

合格项、排序、四槽 P2(发现对+验证对、两对内部独立随机、禁止强制反序)、
F/N 几何冻结(θ\* 在边界时 N=A、F=向内对照)、旧赢家退出基线、categorical
同预算无序表——全部承 v3 §4 不变。

**token 生成【v4.1:双向判定,替换 v4 的"正向打印门通过才发"】**:
1. **来源不可变**:C4 原始 F/N 几何、发现/验证角色、`g_d`、`y` 与 P2 分母全部冻结;
   不得看结果后重定向 `g_d/y`,不得按有无 token 筛选 P2 留出样本。
2. fresh-complete 且质量合格后,同时计算 `J_out = I` 与 `J_in = I_rev`
   (`I=[L,U]` ⇒ `I_rev=[−U/(1−U), −L/(1−L)]`;ρ 不变)。
3. **只有 `lower(J)>τ` 的那个方向**生成一次性来源 token,并记录 action direction。
   两方向不可能同时过门(out 过门要求 max(N)<min(F),in 要求 max(F)<min(N),
   正延迟下互斥)⇒ 每 source contrast 至多一个 token 自动保持;不对增益盲取绝对值。
4. 原墙向 g 按原打印门**带符号**照常披露;行动方向与反向区间旁列,不覆盖原墙向事实。

token 语义(承 v4 不变):admission 即消费(含随后失败/取消),不退款、不递归;
每来源至多一次;当下无预算但来源有效 ⇒ 保持未消费供同候选后续空间评估
(接收空间用自己的 Q/B 付费);提交时重新检查来源未被否定/当前适用/合法新点/预算。

**来源新旧纪律【v4.1 细化方向语义】**:更新的**同可比对象完整 C4** 若墙向转负,
撤销旧 outward 资格;若其 `J_in` 合格,可生成**新来源**的 inward token。
更新的完整 unknown 仍压下旧资格;较新 provisional 形状或 E2 降级对比**不覆盖**
旧完整 C4。同可比对象键 = 同执行身份+精确搭档+轴+冻结 F/N+协议;
immutable contrast ID 标识各次来源——**对象键用于新旧比较,contrast ID 用于唯一消费**,
"ID 不同"不得解读为永不压旧;不同 F/N 是不同条件的有限对比,不按"同轴最新一条"
无差别覆盖。

### 4.2 E 行动:方向贯通的几何与排序【v4.1 修订】

**合格条件(共通)**:存在有效未消费 token(其 action direction 由 §4.1 判定)
且同一 screen-fit 分量内存在该搭档下未测延迟的合法新值。r 备忘:分量内合法
不同轴值数 r≤2 ⇒ C4 后无 E 新点(几何硬约束,可用性报告单列);r≥3 仅必要非充分。

**选点几何【v4.1:按方向镜像,替换单向规则】**:

| 行动方向 | 首选延伸 | 区间内细化 |
|---|---|---|
| outward | N 外侧朝墙紧邻的 screen-fit 未测值 | 未测值距有利端 N 最近优先 |
| inward | F 外侧离墙紧邻的 screen-fit 未测值 | 未测值距有利端 F 最近优先 |

两方向共通:同一已知 screen-fit 分量、不跨 unknown/拒绝/缺口、完整参数合法、
完整生产 trial。若保留相反一侧的最后回退,须标注为**几何回退**,不得冒称已有
该移动方向的改善证据。这只镜像旧优先序,不增加预测器。

**协议菜单(承 v4 裁决②不变)**:E1(默认,1 槽,不产生新认证斜率/新双端 ρ/新 P2)
/ E2(预登记,2 槽,降级新对比)/ E4(4 槽,新曲线研究)。协议按问题与事前几何
预选,不看结果后改名;**预登记的 E2/E4 不因预算不足自动降级为 E1**(除非事前有
预设降级规则;默认 E1 只适用于实际选定了 E1)。

**排序【v4.1:分数同向化】**:先按声明 choice 步跨度分层(跨轴单位不可比),
层间稳定轮转;层内按最新兼容已完成对比的方向化增益降序——
**outward 用 `mean(log F)−mean(log N)`,inward 用 `mean(log N)−mean(log F)`**
(对应方向过 J 门后此分数必为正)→ 最少 E 准入 → 最长等待 → 稳定 ID。
排除条款改述为"**没有合格改善行动方向**的来源不进队列"——不得按原墙向负号
排掉已合格的 inward 来源。不从历史多段挑最大;不用 spill/choice 或跨资源标量。

### 4.3 完成钩子:立即评估,不是立即执行【v4.1 消歧】

C4 第四个 trial fresh-complete 后**立即评估**(来源门→token→新点→预算),
不等下一个 10-told 检查点;带 token 的来源在下次决策获一次优先消费权。
**分开记录并计时 `C_complete→admit` 与 `admit→start` 两段**;适用性检查发生在
**ADMISSION 时刻**:已获准入的点保留 committed 完整 PARAMS 与源执行身份执行,
**不换成 live partners**。若提交后 incumbent 换了搭档,记
`current-at-admission / historical-at-start` 双标注——这不同于整个执行身份改变
(后者按既有不兼容/失败语义处理,不得继续声称来源条件相同);
也**不授权**在 admission 时故意选择已历史化搭档(历史冻结上下文 E 仍挂起,§11)。
钩子只调度既有扫描预算,不在 cadence 外发探针批、不加赠槽、不凌驾空间结束。

### 4.4 相位语义【v4.1 作者选定,采 E 分析 §3.2 推荐表】

普通准入承 v3:requested 相位无合格项回退另一队列,记录 requested/served,
**按 requested 翻转**;token 优先准入为独立路径:

| C 准入 requested/served | C 后普通相位 | token 优先 E 准入后的相位 |
|---|---|---|
| C / C | E | **显式设 C** |
| E / C(fallback) | C | **显式设 C** |

优先准入执行该 token **登记的 action kind**(E1/E2/E4),不强制 E1;
成功 admission 后显式设相位为 C(与 requested 无关);未能准入则相位不变、
token 不消费;**不做"先套普通 flip 再 restore"**。此为显式选定的策略,
不宣称唯一正确;实施前可复议,复议须给出替代表并明确选定。

**必报计数(承 v4)**:accepted/admitted、fresh-completed、distinct new values、
actual rank-changed selections;E 机会漏斗按八门三态 bitset(pass/fail/unknown)
+固定首失败序(X,C,F,P,G,A,N,S),禁止独立相乘与重叠相加。

## 5. 打印门与统计(v4.1 修订 ρ 可观测性)

I/ρ/τ 门、g_d/y/g_all 角色、覆盖率推导(n 对区间覆盖 `1−2^(1−n)`)、
20-timing 嵌套性——全部承 v3 §5 不变。

**ρ 的观测层级【v4.1:替换 v4 的"既有 20-timing 免费测 ρ 量级"】**:
- 单 trial 的 20 个 timing 只能给 **trial 内条件噪声代理**(log 尺度 MAD、
  前后半段差、lag-1 自相关、组内重采样敏感性)——质量门输入,是提示不是 ρ。
- **实际 ρ 定义在跨 fresh trial 的重复差上**:同一完整配置、相同执行条件下
  至少两次真实 fresh trial;双端 ρ 须两端各有这样的重复。
- 自然历史含兼容重复时可分层计算观察 ρ(**缓存复制、换 trial_id 不算重复**);
  没有 fresh 重复 ⇒ ρ 记 **UNKNOWN**,不从 raw CV 或 trial 内代理补值。
- 高斯代入的"两端 max ρ>4% 约 78%"仅保留为**条件模型诊断**(其假设:raw CV=.16、
  iid 正态、n=20 渐近、trial 独立、端点重复差独立),不写成实际 E 失败率;
  CV 不识别中位数方差(长尾构造下中位数可极稳),真实 ρ 分布未知,不据此改门。
- observe 是零额外 **latency trial**,主动编译探针照常付费,主机成本非零。

统计协议变更(C3、弱行动门、`L>4%`)全部暂缓(裁决⑤)。

**RR vs C/E 对照【v4.1:估计对象收窄,替换 v3/v4 继承的宽泛解释】**:
- 两臂**共享**:token 资格门、方向判定(J_out/J_in)、C/E 相位、优先消费钩子、
  U/W/Pcap/Q/D/协议选择规则——即 **RR 臂也在使用斜率**(用于资格与方向)。
- 唯一差别:同层多来源竞争时,处理臂按 §4.2 方向化增益排序,RR 臂按稳定轮转。
- 因此对照回答的是"**同层来源竞争时按增益大小优先是否有用**",
  **不是**"斜率改变搜索目标是否有用"——后一措辞废止,两种解释不得混用。
- **单来源池事实(设计依据)**:冷启动+串行完成 C+即时消费+无继承 pending 下,
  归纳可证每次 E 决策的合格来源池 ≤1 ⇒ 该轨迹上两臂选择必然相同,
  增益排序价值**结构性不可识别**。这是应披露的取舍(即时消费利于施用、
  可能不利于识别排序价值),不是机制缺陷;延迟消费积攒来源损害 freshness
  且争夺 Q,**不作默认修法**。
- **决策记录(最小修补)**:每次 E 决策记 pending 总数、当前 eligible 数、
  同跨度竞争集大小;同一 policy snapshot 下保存 RR target、gain target、
  实际选择与差异频数——RR target 从快照**纯计算**(不调 TPE ask、
  不动 RNG/队列/游标)。`eligible≥2` 分层在新点结果出现前定义。
- **判读纪律**:实际竞争机会为 0 ⇒ 结论是"本样本未识别增益排序价值",
  不是排序有效、无效或 C2 为假;机制永久产生相同选择时,多跑相同路径
  仍不可识别(不是功效不足)。E1="施用事件"仅为仪器口径,
  不自动解释为反事实目标确实改变;来源被用、选中好新点、完整 C2 成立是三件事。
- 可选另批(不是默认、不替代 RR 设计):slope-aware vs blind-geometric
  (盲臂不按实测门/方向决定行动,匹配 C4/Q/B 与合法几何,不伪造打印证据,
  不强制行动剂量配平)——检验单 token 的 USE 效应,须另行批准。
