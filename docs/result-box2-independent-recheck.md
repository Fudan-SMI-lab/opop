## 三、独立复核 2:S1b 原判据的否证(两台机几乎一致)

| 变体 | box 2 取值级误杀 | box 1 |

**68.8% vs 67.5% —— 这个否证在两台机上几乎相同,不是单机偶然。** `median-M` 自适应导致极早开火是机制性的。

**同时修正 register 里那条「N=6 误杀 38.5%」**:那是**旧语料**上的数字。在 box 2 现存的这 4 个 run 上,计数式 N=6 读出 **0.0%**。所以那 38.5% 对应的 run 已不在这台机上(机器重装或目录被清过),**该证据已永久丢失**。这不影响结论(否决黑名单还有 box 1 的 2.3% 与本文的 16.0%@N=3 两条),但**必须记下来,不能继续引用 38.5% 说它可复现**。

## 五、需要修正的一条:J1b-2 的判据写法错了

用出厂代码跑 box 2:

| 汇总范围 | 规则 | 省下失败 | 误杀 | 95% 上界 |
|---|---|---|---|---|
| 每空间 | 6 | 17 | 0 | ≤39.3% (n=6) |
| **每候选(出厂)** | **9** | **37** | **0** | ≤28.3% (n=9) |
| 整 run(跨候选) | 4 | 25 | **1** | **3.85%** |

| 判据 | box 2 | 说明 |
|---|---|---|
| **J1b-1** 误杀 0 | ✅ **0** | 独立成立 |
| **J1b-2** 省 ≥ 200 | ❌ **37** | **判据写法错了,见下** |
| **J1b-7** per-candidate | ✅ 9 条 vs 跨候选 4 条 | |
| **J1b-9** 报上界 | ✅ | |

**J1b-2 的「≥ 200」是我从 box 1 的绝对数字定的,那是错的** —— 收益必然与 `correctness_mismatch` 池子大小成比例,而 box 2 的池子只有 123 个(box 1 是 537)。按池子归一化:

| | 省下 / 池子 |
|---|---|
| box 1 | 228 / 537 = **42.5%** |
| box 2 | 37 / 123 = **30.1%** |

**两台机同量级(30–43%),机制表现一致。** 绝对阈值把「语料小」误报成「机制失效」——**与我在 S1 上引用绝对数字 18% 的错误同形**。

**修正后的 J1b-2**:**省下的 `correctness_mismatch` trial ≥ 该语料该类失败总数的 25%**(box 1 实测 42.5%、box 2 实测 30.1%)。

## 六、一个反向对照第一次自己触发了

**跨候选那一档在 box 2 上真的误杀了 1 个**(3.85%,并触发 1 次撤回),而在 box 1 上是 0。

**这是 J1b-7 的正对照第一次在真实语料上失败** —— 此前它只有「证据强度不足(0/4 上界 52.7%)」和「阈值留一不稳定」两条间接理由;现在它有一条直接的:**跨候选汇总会误杀,per-candidate 不会。** 原理判断被实测追认。
